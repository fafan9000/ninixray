# NiniXray — 3x-ui on Railway

Real Xray-core + 3x-ui panel (like Sanaei panel) deployed on Railway.

## Deploy
1. Railway → New Project → Deploy from GitHub repo → `fafan9000/ninixray`
2. Set variables: `PANEL_USER`, `PANEL_PASS`, `PANEL_PATH`
3. Generate domain → open `https://<domain>/<PANEL_PATH>/`

Defaults: user/pass `reza4343`/`reza4343`, path `/n/`
